# Rounded container system

The user rejected the earlier custom W-cut and Offset shapes. The current approved direction uses simple rounded containers: 28px hero artwork/film, 24px project/panel, 16–20px cards and images. No SVG clips or branding frame exports are used. Keep all text and controls within normal rectangular content flow.

White is the primary canvas. Charcoal #222629 anchors visual panels and body copy; green #86C232 provides emphasis and buttons. Use the supplied logo unchanged. Preserve keyboard focus, responsive layout and reduced motion. The hero artwork uses bounded pointer motion and native scroll depth; it becomes static with reduced motion.
