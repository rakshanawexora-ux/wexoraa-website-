# Wexoraa signature container

An original supporting brand shape derived from the rhythm of the supplied W mark: two rounded valleys in the upper-right edge, with a lifted diagonal lower-left corner. The official logo is unchanged. The Phenomenon Studio reference could not be inspected because outbound access was blocked; this geometry is a Wexoraa-specific proposal, not a copy or an asserted reference match.

## Files

- `src/brand/signature.ts`: normalized geometry, the single web source.
- `src/components/brand-frame-defs.tsx`: one global decorative SVG clip definition.
- `.signature-frame`: reusable container class.
- `public/brand/wexoraa-signature-frame.svg`: green master, 1200 × 700.
- `public/brand/wexoraa-signature-frame-charcoal.svg`: charcoal variation.
- `public/brand/wexoraa-signature-frame-outline.svg`: outline variation.
- Regenerate artwork after changing geometry: `node scripts/export-brand-frame.mjs`.

## Application

Use on selected hero, project, motion and service-illustration containers. Keep ordinary forms, buttons and reading panels simple. On white backgrounds the negative-space W reads clearly. Do not place important text in the cut-out or lower-left diagonal; reserve generous content padding and keep focus indicators inset on clipped links. Wide-screen hero metadata is positioned below the notch, while the mobile stamp is shortened to remain clear of it. Sticky ancestors are not clipped; the project feature surface inside the sticky stage carries the shape.

For fixed branding artwork, preserve the master SVG proportions. The website intentionally adapts the same normalized geometry to responsive feature containers. Green is #86C232, charcoal is #222629, supporting colours remain #61892F / #474B4F / #6B6E70. Use the outline variation on quieter layouts. Keep the W feature at the upper right and the diagonal at the lower left to build consistent recognition.
